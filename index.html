先进先出

批次不仅用于追溯，也用于安排领用顺序

覆盖原辅料、包材、半成品及成品；有有效期的物料优先考虑近效期。

FIFO / 近效期优先
  1. 01 / 建档

    来料与标签

    核对供应商批次资料，建立物料编码、批次、日期、数量和质检状态。

  2. 02 / 判定

    先判断是否可用

    待检料检验合格后才计可用；过期、不合格及异常料隔离，禁止使用，按处置结论处理。

  3. 03 / 发料

    依批次规则发料

    原辅料按入库先后，成品按生产日期 / 批次；适用时近效期优先。

  4. 04 / 退料

    保留原批次

    整理包装，记录原批次、原入库信息和退料日期，纳入后续优先领用。

  5. 05 / 复核

    盘点与稽查

    按编码、批次、数量、库位与有效期核对，更新呆滞和临期清单。

正常按规则，例外须审批

PMC / 系统给出批次领料要求，仓库据此发料，生产人员不得自行挑选新料。特殊订单需优先新料时，主管审批并留痕；系统如何放行后续细化。

标签与台账先可执行

标签含名称、编码、供应商、批次、生产 / 入库日期、有效期、数量及质检状态。无系统时用共享台账，仓库领料前核对，PMC 同步审核。

库位组织沿用已确认边界

不同批次是否混放，以该系统设置的为准。原制度的 新旧料双区仅作为物理组织参考，不在本稿中设为所有物料必须遵循的库位模式。

03

按阶段核齐套，凭确认单交计划

跟单为第一责任人，仓库、品质分别背书；进入计划专员即封板，随后安排排产。

齐套的判断口径

不是“到货了”就算齐套，而是四个条件同时满足

阶段范围为本稿整合
数量可用数量满足本次开工需求，缺料有明确跟催记录。
品质检验合格且状态有效；待检、不合格物料不计齐套。
账物实物、台账、批次与对应物料信息一致。
时间满足本阶段开工时点，承诺到货不等于已经可用。
本次执行阶段齐套率 = 已齐套物料项数 ÷ 完整 BOM 中本阶段物料总项数 × 100%采用制度的“物料项数”口径；以完整 BOM / 工艺路线中本次执行阶段的物料范围核算，不按物料数量加权。

每项都需四条件成立，关键物料不能用平均齐套率掩盖。整单保留所有阶段的物料总览，本次开工按对应阶段核算；未确认的后续包装不阻断已确认的光杯阶段。本稿仍按“齐套后交计划”处理。

仓库签认

数量与账物是否一致；到货日期、数量与批次是否真实。

品质签认

来料是否合格；待检、不合格与替代料是否已明确处置。

业务跟单签认并提报

一单一表持续跟踪，汇总齐套结论，提报《订单物料齐套确认单》。

现行三方签认缺一，不进入正式排产。不得代签、补签、事后追签。资料与签认不完整时先补齐，再交付封板。

来源：齐套制度 · 第 2–4 页。按完整 BOM 中本次执行阶段的物料范围核算齐套。

未来系统判断物料

条件满足后启用

不再要求仓库主管、品质的人工签字；数量、账物及检验结论仍需有效，业务跟单员按既有流程确认。后续计划安排仍由计划专员负责。

缺料闭环

未齐套 → 采购跟催 / 品质处置 / 外协催回 → 重新判定；未定义的“条件排产”本稿暂不开放。

封板后：只有执行与停止

进入计划专员环节即视为封板。封板内容不得修改，哪怕只改一个物料编码。

↗ 执行原计划

按已封板的物料、BOM 与工艺内容推进，守住已确认的执行范围。

■ 必须变更：先停止，再走新流程

紧急停止原计划，另开一条新线，重新走前置流程。

  1. 原计划紧急停止
  2. 新开流程
  3. 重走资料、齐套与审批
  4. 重新评估、排产与新封板

谁发起变更，谁承担相应责任。已从产线撤下的产品，变更产生的责任同样需要落实。新流程仍须遵循“进入计划专员即封板”的规则，并完成重新评估与排产。

04

前后工序，凭据交接、当面确认

把现场的实物流、数量流和责任记录同步起来，交接凭证进入报工数据链。

工序物料管理

标准容器 + 流转凭证 + 双方确认

工序间暂放区设容量上限；具体容器容量与区域上限按现场核定。

无凭证不交接
  1. 01 / 前道

    合格品装载附卡

    按标准容器装载，标明数量、生产单、物料与下一工序。

  2. 02 / 交接点

    后道到点领取

    前后道共同在场，指定交接点领取，禁止未经确认直接投产。

  3. 03 / 共同

    清点与外观初检

    核实实交实收及外观状态，可按标准容器核数，不凭估计交接。

  4. 04 / 签认

    接收人签名记时

    无误后签认；前道留副联或电子记录，正联随物料流转。

  5. 05 / 统计

    汇总归档与核对

    统计每日收集凭证，汇总现场完成情况并核对在制品与系统。

交接记录的核心关联字段

订单 / 阶段物料编码与名称批次号前道 / 后道工序实交 / 实收数量及单位品质状态交接双方与时间连续凭证号

物料编码、批次与阶段字段按已确认的管理基础补入；规格、材质、型号、人员、产线、生产时间等随流转卡保留。

数量短缺 / 溢出

在凭证上记录实收数量，双方共同核对签认，进入《交接异常记录表》。短缺由前道补足；溢出由班组长查明计数、标准容量或超产原因，不能直接覆盖原记录。

质量异常 / 拒收

后道可拒收批量质量异常，物料隔离待判，通知前道班组长与 IPQC。仍记录实物数量、批次、位置与异常状态，暂不作合格交接或投料确认；处置后按新指令交接。

签收凭证是现场产量依据，不直接等于工资结算。班组长、主管、车间统计监督交接、处理争议，并定期盘点在制品。凭证连续编号、规范留存，修正保留原记录及责任信息。

来源：工序流转制度 · 第 2–4 页。质量异常“仍记录数量、暂不合格交接”为本稿为防止数据断档作的整合修正。

仍关联原订单
完整方案，分阶段执行

一笔订单对应完整的 BOM / 工艺路线，按客户确认进度分阶段交付与执行。各阶段围绕已确认内容推进，光杯入库后再衔接后续工艺。

确认的是本次要做的内容

首次封板时，相应内容已经过业务主管确认、最终客户确认。对应阶段的物料先完成齐套校验，再交给计划专员安排。后续雕花、颜色、包装等尚未确认的部分，可留待后续阶段确认。

后续阶段确认，不回改已封板阶段

在完整 BOM / 工艺路线中，按客户确认进度明确后续阶段的喷涂、抛光、物料及包装要求，再按相同流程确认与封板。

如果涉及已封板内容的变更，仍须停止原计划 → 新开流程 → 重新评估、封板与排产，并落实发起人的相应责任。
